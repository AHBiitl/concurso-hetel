# concurso-hetel

## Minijuego de contraseñas

El análisis, la puntuación y las recomendaciones se calculan localmente en el navegador; la contraseña no se envía a un servidor ni a un servicio externo y no se guarda en el progreso. La puntuación sobre 200 muestra su cálculo por pasos: longitud, variedad, bonificaciones y penalizaciones por patrones previsibles. Es una guía educativa, no una garantía de seguridad ni una comprobación de filtraciones. Usa únicamente contraseñas ficticias.
